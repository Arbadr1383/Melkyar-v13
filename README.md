# ملک‌یار — نسخه اصلی

این آرشیو **نسخه اصلی و بدون سیستم لایسنس** است.

- بدون کد فعال‌سازی
- بدون فایل یا وابستگی لایسنس
- بدون محدودیت زمانی
- شامل ماژول دستیار هوشمند آفلاین
- شامل اصلاح بخش ثبت کمیسیون و نمایش معاملات در فرم کمیسیون

این نسخه برای استفاده اصلی/نامحدود است.

## Cloudflare Web / D1
این پروژه برای دو حالت طراحی شده است:
- Electron: همچنان از IndexedDB محلی استفاده می‌کند و EXE دسکتاپ تغییر معماری نمی‌دهد.
- Web/PWA: فایل `js/database.js` به API `/api/db` متصل می‌شود و داده‌ها در Cloudflare D1 مشترک ذخیره می‌شوند.

برای Cloudflare:
1. یک D1 با نام `melkyar-db` بسازید.
2. `schema.sql` را اجرا کنید.
3. مقدار واقعی Database ID را در `wrangler.toml` جایگزین `PASTE_D1_DATABASE_ID_HERE` کنید.
4. پروژه را به Cloudflare Pages متصل کنید؛ Build command می‌تواند `npm run build:cloud` و output directory `.` باشد.
